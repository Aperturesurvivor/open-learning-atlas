# Code of Conduct

Open Learning Atlas depends on disagreement being specific, inspectable, and
safe to participate in. Contributors and maintainers must:

- critique claims, definitions, evidence, and methods rather than people;
- state uncertainty and scope honestly;
- welcome correction without using status or credentials to silence evidence;
- avoid harassment, demeaning language, sexualized conduct, threats, and
  discriminatory behavior;
- never publish another person's private information without permission;
- make room for learners and nontraditional contributors while remaining clear
  about the review dimensions their experience can support;
- disclose conflicts of interest that could affect map or governance decisions.

This standard applies in repository issues, pull requests, reviews, discussions,
project events, and public representation of the project.

Maintainers may edit or remove contributions, restrict participation, or refer
conduct to the hosting platform when needed to protect participants and the
project. Reasons for moderation should be documented when doing so would not
increase harm or expose private information.

Until a dedicated confidential conduct address exists, contact the founding
maintainer through the Aperturesurvivor GitHub profile and request a private
channel without including sensitive details in a public issue.
