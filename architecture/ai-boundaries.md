# AI Boundaries

## Use AI For Base-Map Work

- Proposing candidate nodes and capability decompositions.
- Searching for possible duplicates and missing relationships.
- Comparing definitions and relationship rationales.
- Checking schema, terminology, and internal consistency.
- Processing research and source material into review candidates.
- Generating non-authoritative views and documentation.

## Do Not Use AI For

- Silent changes to accepted record meaning.
- Promotion of its own candidates to accepted status.
- Fabricated provenance, consensus, or empirical support.
- Hidden prerequisite claims.
- Bulk imports without accountable human review.
- Conflating conventional school order with mathematical necessity.

## Pattern

```text
AI proposes -> schema and semantic checks run -> accountable review decides
```

The earlier tutor, hint, answer-key, and parent-summary boundaries remain useful
for downstream applications but do not define the base map.
