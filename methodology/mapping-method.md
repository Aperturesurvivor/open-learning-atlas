# Open Learning Atlas Mapping Method

## One-Sentence Definition

Open Learning Atlas turns an educational domain into a typed, versioned map of
concepts and observable capabilities whose relationships remain inspectable,
conditional, sourced, and revisable.

## Core Model

```text
domain boundary
-> candidate terrain
-> bounded capabilities
-> typed relationship claims
-> review and provenance
-> validation
-> versioned reference map
```

## Pillars

1. Educational terrain is a graph, not a course sequence.
2. Observable capability is the central educational unit.
3. Concepts, knowledge, representations, practices, and composites remain
   distinguishable.
4. Relationships are claims, not anonymous arrows.
5. Absence means unmapped, not nonexistent.
6. Identity survives renaming and reorganization.
7. Disagreement and uncertainty remain visible.
8. Curricula, learners, projects, assessments, and applications are downstream.
9. AI may propose and inspect; accountable review establishes the reference
   map.

## Mapping Cycle

1. Define the domain and explicit exclusions.
2. Sketch its low-resolution topology without grade or course boundaries.
3. Identify concepts, knowledge, representations, and practices because
   observable capabilities need to reference them.
4. Write bounded capability statements using the constitutional grammar.
5. Apply the split tests until independent failures have independent nodes.
6. Add typed edges with rationale, scope, confidence, and provenance.
7. Use conditional requirement groups where alternative routes exist.
8. Mark dependency review as unreviewed, partial, or reviewed-complete.
9. Validate the machine-readable graph.
10. Review mathematical correctness, observability, granularity, relationship
    semantics, and backwards compatibility separately.
11. Release an immutable snapshot and continue mapping under the open-world
    assumption.

## Capability Evidence Boundary

The base map may name broad dimensions along which a capability could be
observed:

- accuracy;
- independence;
- representation;
- explanation or justification;
- fluency;
- variation;
- retention;
- transfer;
- error analysis.

It does not define a particular test, cut score, timing rule, learner state, or
mastery algorithm. Those systems may later reference map IDs.

## Current Scope

The current work is the base map itself, with mathematics as the first domain.
The earlier learner-advancement and iPad-app method remains downstream evidence
that a map can drive software; it no longer determines the map architecture.
