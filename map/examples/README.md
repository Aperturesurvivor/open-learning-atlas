# Example Maps

Examples are pressure tests for the constitution and schema. They are candidate
records, not settled mathematics maps or prescribed sequences.

## Rational And Proportional Seed

[`rational-proportional-v0.1.json`](rational-proportional-v0.1.json) contains:

- 18 typed nodes;
- 25 first-class edge claims;
- 1 conditional alternative-method requirement group;
- explicit open-world dependency-review state;
- contributor-analysis provenance rather than false empirical authority.

Important design demonstrations:

- fraction notation is separate from rational number and ratio concepts;
- observable interpretation is separate from the notation itself;
- number-line competence supports rational comparison without becoming its
  only valid route;
- equivalent-ratio and unit-rate methods remain alternatives rather than two
  universal prerequisites;
- proportional reasoning is a non-assessable navigation composite.

Validate it with:

```sh
tools/validate-map map/examples/rational-proportional-v0.1.json
```
