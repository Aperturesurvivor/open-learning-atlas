# Open Learning Atlas: Mathematics 0.2.0-alpha

Revised public alpha with a non-destructive advanced-analysis split and stronger source-specific coverage evidence.

## Changes

- Split the over-aggregated Measure, Functional, Complex, and Harmonic Analysis territory into three reviewable successor territories.
- Preserved the original stable identity and its historical composition claims as deprecated records.
- Added a machine-readable migration and explicit one-to-many redirect for downstream consumers.
- Added dedicated MIT OpenCourseWare coverage sources for functional, complex, and Fourier analysis.
- Defined active structural traversal to exclude deprecated nodes and relationships while keeping them directly inspectable.
- Raised the connected active map from 85 to 87 territories without changing the v1 measurable breadth floor.

## Known limitations

- All mathematical records and relationships remain candidates or deprecated historical records; structural validation is not expert acceptance.
- Most dependency declarations remain unreviewed and the graph contains only a pressure-test set of requires claims.
- Coverage breadth is machine-audited, but qualitative scope, granularity, duplication, and correctness review remains open.
- The release is an alpha format and is not Open Learning Atlas: Mathematics v1.0.
