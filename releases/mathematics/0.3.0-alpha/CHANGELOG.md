# Open Learning Atlas: Mathematics 0.3.0-alpha

Release-infrastructure alpha with self-contained migration history, a machine-readable current-release pointer, and validated cross-release identity invariants.

## Changes

- Introduced package format 0.2, bundling the migration schema and applicable or historical migration documents inside the checksummed release archive.
- Added a deterministic machine-readable pointer to the current dataset, package, manifest, checksums, tag, viewer, and public data URL.
- Added cross-release validation that rejects stable-identity removal, unversioned record mutation, revision rollback, deprecated-identity reactivation, and undocumented node lifecycle changes.
- Required every active territory to cite field-appropriate coverage evidence beyond the whole-field MSC2020 breadth checklist, correcting the rational-and-proportional source assignment.
- Corrected the v1 completion contract to name all 87 active territories.
- Made no mathematical node or relationship changes from 0.2.0-alpha.

## Known limitations

- All active mathematical records and relationships remain candidates; structural validation is not expert acceptance.
- Most dependency declarations remain unreviewed and the graph contains only a pressure-test set of requires claims.
- Coverage breadth is machine-audited, but qualitative scope, granularity, duplication, and correctness review remains open.
- The release is an alpha format and is not Open Learning Atlas: Mathematics v1.0.
