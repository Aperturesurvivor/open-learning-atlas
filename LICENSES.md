# Licensing

Open Learning Atlas separates software rights from atlas-content rights so
downstream users can understand exactly what they may reuse.

| Material | License |
| --- | --- |
| Source code, schemas, build scripts, validators, and viewer software | Apache License 2.0 |
| Canonical atlas data, authored definitions, methodology, and documentation | Creative Commons Attribution 4.0 International |
| Names, logos, and project marks | Not licensed as trademarks by either license |
| Third-party sources and citations | Their original terms; citation does not relicense source material |

The Apache-2.0 text is in [`LICENSE`](LICENSE). The CC BY 4.0 legal code is in
[`LICENSES/CC-BY-4.0.txt`](LICENSES/CC-BY-4.0.txt).

## Attribution

A reasonable attribution for reused atlas data is:

> Open Learning Atlas contributors, *Open Learning Atlas: Mathematics*,
> version or commit identifier, licensed under CC BY 4.0.

When publishing a modified dataset, identify that it was modified and retain a
link to the source release. Attribution must not imply endorsement by Josiah
Wilson, maintainers, reviewers, or contributors.

## Why These Licenses

Apache-2.0 is an OSI-approved permissive software license with an explicit
patent grant. CC BY 4.0 permits sharing and adaptation, including commercial
reuse, while requiring attribution and addressing applicable database rights.
This combination favors interoperability without imposing a share-alike
license on every downstream curriculum, application, or analysis.
