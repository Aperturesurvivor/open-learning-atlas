# Roadmap to Mathematics v1.0

The binding definition of done is
[`docs/v1-completion-contract.md`](../docs/v1-completion-contract.md).
This roadmap describes order of work, not permission to reduce that contract.

## Phase 0: Public Foundation

- Ratify the base-map constitution.
- Establish the Open Learning Atlas identity and `ola:` namespace.
- Publish schema, semantic validator, licenses, contribution terms, governance,
  human/agent access requirements, and an honest project dossier.
- Create a clean public-history repository.

**State:** implementation in progress; core documents and validation exist.

## Phase 1: Decomposition Standard

- Define territory, capability-family, and atomic-capability resolution.
- Define source, review, duplicate-detection, and decomposition worksheets.
- Pressure-test the method on contrasting mathematical territories.
- Extend validation to the v1 completion invariants.

## Phase 2: Whole-Atlas Expansion

- Decompose all 85 territories to the v1 coverage floor.
- Share cross-region identities instead of duplicating concepts or capabilities.
- Map conditional dependencies and alternative methods without importing
  conventional course order.
- Add territory-level coverage notes and preserve candidate status honestly.

## Phase 3: Release Infrastructure

- Generate deterministic snapshots, manifests, checksums, statistics, diffs,
  redirects, changelogs, and license manifests.
- Add CI for schema, semantic, link, accessibility, test, and build checks.
- Publish pinned data and schema URLs suitable for agents and software.

## Phase 4: Mobile Atlas

- Design and implement the complete interactive experience from canonical data.
- Support search, progressive zoom, filters, node and edge inspection, and deep links.
- Verify phone, desktop, keyboard, screen-reader, contrast, and reduced-motion use.
- Deploy the generated site through GitHub Pages.

## Phase 5: v1 Completion Audit

- Produce direct evidence for every completion-contract requirement.
- Run release reconstruction and downstream conformance fixtures.
- Publish known limitations and status distributions.
- Tag and publish Mathematics v1.0 only when the audit proves completion.
